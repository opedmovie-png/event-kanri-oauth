プライバシーポリシー

「イベント管理」は開発者本人のみが使用する個人用ツールです。

  • Google アカウントのデータ（Gmail・Google カレンダー・Google ドライブ・Google スプレッドシート）は、本人のチケット申込と参加記録の管理にのみ使用します。
  • 取得したデータは本人の Google アカウントと本人の端末にのみ保存し、第三者に提供・販売しません。
  • 広告や本人以外へのサービス提供には使用しません。
  • 連携は Google アカウントの設定からいつでも解除できます。

Google API から受け取った情報の使用と他のアプリへの転送は、限定使用の要件を含む Google API サービスのユーザーデータに関するポリシーに従います。
